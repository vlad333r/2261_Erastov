### Задание 1 **(2)**
*Переведите в двоичную запись два произвольных рациональных числа (числа вида* $\frac{p}{q}$).
*У одного из чисел знаменатель должен быть степенью двойки (32), а у другого --- некоторым числом
от 9 до 12.*

*Запись второго числа будет содержать период. Его надо найти. При решении задачи нельзя 
использовать вычислительную технику. Процесс решения должен быть представлен в отчете.*

### Ответ:

Берем 23/32 и 7/12

23 = (10111)₂, а 32 = 2^5. Переносим точку на 5 разрядов влево:

23/32 = (0.10111)₂

Для 7/12 удваиваем дробную часть:

```text
7/12 · 2 = 1 + 2/12
2/12 · 2 = 0 + 4/12
4/12 · 2 = 0 + 8/12
8/12 · 2 = 1 + 4/12
```

Целые части дают биты 1001 
7/12 = (0.10(01))₂. Период: 01

### Задание 3 **(3)**
*Найдите сумму и произведение для записанных далее пар чисел. Числа заданы в двоичной записи

* 1.0011e18 и $1.1001e21;

*При решении задачи нельзя 
использовать вычислительную технику. Процесс решения должен быть представлен в отчете.*

### Ответ:

Здесь e означает степень двойки. Для суммы выравниваем порядки, для произведения перемножаем мантиссы и складываем порядки.

#### 1.0011e18 и 1.1001e21

Сумма. Разность порядков: 21 - 18 = 3. Сдвигаем точку первой мантиссы на 3 разряда влево и увеличиваем ее порядок до 21:

```text
1.0011·2^18 = 0.0010011·2^21.
```

складываем мантиссы:

```text
  1.1001000
+ 0.0010011
```

Сумма: 1.1011011e21

Произведение. Складываем порядки: 18 + 21 = 39. Для умножения мантисс временно убираем точки. У каждого множителя 4 дробных бита, поэтому у произведения будет 8.

В двоичном умножении каждый единичный бит второго множителя дает сдвинутую копию первого. Нулевые строки пропускаем:

```text
10011 · 11001:

  000010011
+ 010011000
+ 100110000

```
Возвращаем 8 дробных бит и нормализуем:
Произведение: 1.11011011e39.


#### 1.1011e-25 и 1.1101e-23

Сумма. Разность порядков: -23 - (-25) = 2. Сдвигаем точку первой мантиссы на 2 разряда влево:

```text
1.1011·2^(-25) = 0.011011·2^(-23).
```

Складываем мантиссы при одинаковом порядке:

```text
   1.110100
+  0.011011

  10.001111
```

Мантисса начинается с 10. Сдвигаем точку на один разряд влево и увеличиваем порядок на 1:

```text
10.001111·2^(-23) = 1.0001111·2^(-22).
```

Сумма: 1.0001111e-22.

Произведение. Складываем порядки: -25 + (-23) = -48. Убираем точки и перемножаем двоичные числа:

```text
11011 · 11101:

  0000011011
+ 0001101100
+ 0011011000
+ 0110110000
```

Возвращаем 8 дробных бит и нормализуем:

```text
11.00001111·2^(-48) = 1.100001111·2^(-47).
```

Произведение: 1.100001111e-47.

#### 1.1011e-3 и 1.1011e1

Сумма. Разность порядков: 1 - (-3) = 4. Сдвигаем точку первой мантиссы на 4 разряда влево:

```text
1.1011·2^(-3) = 0.00011011·2^1.
```

Складываем мантиссы:

```text
  1.10110000
+ 0.00011011
```

Сумма: 1.11001011e1.

Произведение. Складываем порядки: -3 + 1 = -2. Убираем точки и умножаем:

```text
11011 · 11011:

  0000011011
+ 0000110110
+ 0011011000
+ 0110110000
```

Возвращаем 8 дробных бит и нормализуем:

```text
10.11011001·2^(-2) = 1.011011001·2^(-1).
```

Произведение: 1.011011001e-1.



### Задание 4 **(2)**

*Рассмотрим следующий пример в IDLE Python*
```
>>> x = 99.99
>>> int(x/10+0.001)

```
*Результат должен был быть равен 10, однако оказался другим. Почему так произошло?

### Ответ:

Из-за двоичного округления получается 9.999999999999998. Функция int отбрасывает дробную часть, поэтому дает 9. Для округления к ближайшему целому:

```python
x = 99.99
print(round(x / 10 + 0.001))
```

Ответ: 10.

### Задание 6 **(2)**

*Для какого минимального значения* $n$ *программа на С++ выведет* **inf**? *Объясните
ответ.* *Что произойдет, если тип* **double** *заменить на* **long double**?
```
int n=...;
double s = pow(2, n);
std::cout << std::fixed << s << std::endl;
```

### Ответ:

Ответ: n = 1024, так как max double = (2−2^−52)·2^1023 < 2^1024.

```cpp
#include <cmath>
#include <iomanip>
#include <iostream>

int main() {
    int n = 1024;
    double s = std::pow(2, n);
    std::cout << std::fixed << s << '\n';
}
```

Замена только типа s не поможет: pow(2, n) вычисляется в double. Нужно:

```cpp
long double s = std::pow(2.0L, n);
```

Для 80-битного long double граница - n = 16384



### Задание 7 **(2)**

*Допишите что-либо вместо многоточия программе на С++, чтобы программа при запуске выдавала ответ* **yes**.
