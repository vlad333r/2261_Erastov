### Задание 1 **(2)**
*Переведите в двоичную запись два произвольных рациональных числа (числа вида* $\frac{p}{q}$).
*У одного из чисел знаменатель должен быть степенью двойки (32), а у другого --- некоторым числом
от 9 до 12.*

*Запись второго числа будет содержать период. Его надо найти. При решении задачи нельзя 
использовать вычислительную технику. Процесс решения должен быть представлен в отчете.*

### Ответ:

Берем 23/32 и 7/12

23 = (10111)₂, а 32 = 2^5. Переносим точку на 5 разрядов влево:

23/32 = (0.10111)₂

Для 7/12 удваиваем дробную часть:

```text
7/12 · 2 = 1 + 2/12
2/12 · 2 = 0 + 4/12
4/12 · 2 = 0 + 8/12
8/12 · 2 = 1 + 4/12
```

Целые части дают биты 1001 
7/12 = (0.10(01))₂. Период: 01

### Задание 6 **(2)**

*Для какого минимального значения* $n$ *программа на С++ выведет* **inf**? *Объясните
ответ.* *Что произойдет, если тип* **double** *заменить на* **long double**?
```
int n=...;
double s = pow(2, n);
std::cout << std::fixed << s << std::endl;
```

### Ответ:

Ответ: n = 1024, так как max double = (2−2^−52)·2^1023 < 2^1024.

```cpp
#include <cmath>
#include <iomanip>
#include <iostream>

int main() {
    int n;
    std::cin >> n;
    double s = std::pow(2, n);
    std::cout << std::fixed << s << '\n';
}
```

Замена только типа s не поможет: pow(2, n) вычисляется в double. Нужно:

```cpp
long double s = std::pow(2.0L, n);
```

Для 80-битного long double граница - n = 16384. Если он совпадает с double - 1024.



### Задание 7 **(2)**

*Допишите что-либо вместо многоточия программе на С++, чтобы программа при запуске выдавала ответ* **yes**.
```
double s = ...;
if (s != s)
  std::cout << "yes";
```

### Ответ:

Нужно NaN: это значение не равно самому себе.

```cpp
#include <iostream>
#include <limits>

int main() {
    double s = std::numeric_limits<double>::quiet_NaN();
    if (s != s)
        std::cout << "yes\n";
}
```

*Какое минимальное натуральное число при преобразовании в тип* **double** *записывается с погрешностью? Объясните
ответ. Почему следующее за ним число уже выводится без погрешности?*

### Ответ:

Ответ: 2^53 + 1 = 9007199254740993.

У double 53 значащих бита. До 2^53 все целые точны, дальше шаг равен 2. Поэтому 2^53+1 округляется до 2^53, а следующее четное число 2^53+2 представляется точно.
