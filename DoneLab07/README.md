### Задание 1 **(2)**
*Оцените работу следующих фрагментов программ. Какие из них обладают неоднозначным поведением? Почему?*
```
int x=10, y=3;
std::cout << std::min(x=15, x+y);
```
```
int x=10, y=3;
x=15, y+=x, x+=y;
```
```
int x=10, y=9;
if (x>y++ && y++>9)
  cout << "yes" << endl;
cout << y;
```

*Тексты программ разместите в папке с номером задания*

### Ответ:

1. При запуске выводится 13. Сначала вычисляется x+y = 10+3 = 13, затем x становится равным 15. Получается min(15, 13) = 13.

2. Запятая выполняет действия слева направо:

```text
x = 15;
y = 3 + 15 = 18;
x = 15 + 18 = 33.
```

3. Сначала сравниваются 10 и 9, затем y становится 10. Второе сравнение тоже истинно: 10 > 9. После него y=11. Вывод:

```text
yes
11
```

У && правая часть проверяется только после левой и только если левая истинна.



### Задание 2 **(2)**
*Как записать следующие строки программы на С++ в виде одного
выражения? Приведите несколько способов, в том числе с использованием операторов инкремента.*
*Проверьте работу написанных программ*
```
x=x+1;
z=z+2*x+3*y;
y=y+1;
```
*Тексты программ разместите в папке с номером задания*

### Ответ:

Три варианта:

```cpp
x = x + 1, z = z + 2 * x + 3 * y, y = y + 1;
```

```cpp
++x, z += 2 * x + 3 * y, ++y;
```

```cpp
z += 2 * ++x + 3 * y++;
```

++x использует новое значение x, а y++ старое значение y. Проверка: из x=2, y=4, z=7 во всех случаях получается x=3, y=5, z=25.

### Задание 4 **(2)**

*Почему присваивание* ```(++x)=y``` *является синтаксически правильным, а*
```(x++)=y``` - *нет? Запишите текст сообщения об ошибке, переведите и объясните его.*

### Ответ:

++x возвращает саму переменную, поэтому ей можно присвоить y. В итоге x будет равен y.

x++ возвращает старое значение x. Это временное значение, присваивать ему нельзя.

Ошибка:

```text
lvalue required as left operand of assignment
```

Перевод: слева от присваивания требуется lvalue, то есть объект, которому можно присвоить значение.




### Задание 5 **(2)**

*Программисты на Python для обмена значений двух переменных часто пишут строку*
```
a,b = b,a
```
*Проверьте, будет ли аналогичная строка на С++ (с точкой с запятой в конце) являться синтаксически
правильной? Будет ли она обменивать значения переменных? Как в языке С++ вычисляется это выражение?*

### Ответ:

Компилируется, но обмена нет. Присваивание выполняется раньше запятой, поэтому выражение разбирается так:

```cpp
a, (b = b), a;
```

Меняется только b, причем ему присваивается его же значение. a и b остаются прежними. Для обмена нужно std::swap(a, b).

```
  std::string s;
  for (int i=0; i<1000000; i++)
     s += 'a';
  std::cout << s.size();
```
*Измените третью строку на*
```
s=s+'a';
```
*Изменится ли что-нибудь в ее работе? Объясните результат.*

### Ответ:

### Задание 7 **(2)**

*Как работает следующая программа? Как зависит результат от исходного значения?*
```
int x;
std::cin >> x;
x-->0 && x-->0 && x-->0 && x-->0 && x-->0;
std::cout << x;
```

### Ответ:

x-->0 разбирается как (x--) > 0. Сравнивается старое x, затем оно уменьшается на 1. После первого ложного сравнения && остальные проверки не выполняет.

Для исходного x результат такой:

```text
x < 0:       x - 1;
0 <= x <= 4: -1;
x >= 5:      x - 5.
```

Например, из 3 получится -1, из 8 получится 3. Исключение: для минимального int происходит переполнение.



### Задание 8 **(3)**

*Какое число выводит следующий фрагмент программы? Посчитайте результат без использования
вычислительной техники. Отчет должен содержать процесс вычислений.*
```
int s = 0;
for (int i = 0, j = 5;i+j <= 16;(i<j ? i : j)++)
   (s += i) += j;
std::cout << s;
```

### Ответ:

Вывод: 126.

(s += i) += j прибавляет к s сначала i, затем j. (i<j ? i : j)++ увеличивает меньшую переменную, а при равенстве увеличивает j.

Значения по проходам:

```text
i  j  i+j
0  5   5
1  5   6
2  5   7
3  5   8
4  5   9
5  5  10
5  6  11
6  6  12
6  7  13
7  7  14
7  8  15
8  8  16
```

Дальше i=8, j=9. Сумма 17, поэтому цикл заканчивается:

```text
s = 5 + 6 + ... + 16 = (5 + 16) * 12 / 2 = 126.
```



###  Задание 9 **(3)**
*Рассмотрите следующую программу. Предполагается, что на вход подается некоторый
индекс в массиве - число от нуля до девяти и значение, которое надо записать по этому индексу.*
```
int i = 0;
std::vector<int> x(10);
std::cin >> i >> x[i];
std::cout << x[i];
```
*Проверьте работу этой программы на различных компиляторах. Найдите два компилятора (можно 
проверить онлайн компиляторы), на которых эта программа будет давать различные ответы при одинаковом
вводе. Как это объяснить?*


### Ответ:

По старым правилам адрес x[i] мог вычисляться до ввода i. При вводе 3 47 тогда число попадало в x[0], а выводился x[3], равный 0.

Если сначала прочитать i, число попадет в x[3] и выведется 47. В современном C++ порядок именно такой.

Отдельные строки ввода убирают эту зависимость:

```cpp

```
