### Задание 1 **(3)**
*Рассмотрим следующую программу на С++.*
```
#include <iostream>
#include <cmath>
int main() {
   double x = 0;
   const auto Pi = std::acos(0) * 2;
   std::cout << Pi << std::endl;
   return 0;
}
```
*Проверьте четыре способа объявления* **Pi**.
* ```const auto Pi = acos(0) * 2;```
* ```constexpr auto Pi = std::acos(0) * 2;```
* ```const auto Pi = acos(x) * 2;```
* ```constexpr auto Pi = std::acos(x) * 2;```

*Что можно сказать об этих вариантах? Проверьте, в каких вариантах объявляется константа этапа трасляции.*

*Тексты программ разместите в папке с номером задания*

### Ответ:

1. const с acos(0): программа работает. Значение Pi нельзя изменить, но вычислять его при компиляции не обязательно.
2. constexpr с acos(0): при проверке работает. Значение Pi вычисляется при компиляции.
3. const с acos(x): программа работает. Pi нельзя изменить, но его значение берется из выражения с обычной переменной x.
4. constexpr с acos(x): ошибка. Переменная x не является константой, хотя ей и присвоен 0.

Главное отличие: const запрещает менять значение, а constexpr требует получить его уже при компиляции. Поэтому во втором варианте Pi является константой этапа трансляции.

Второй вариант сработает только там, где acos поддерживает вычисление при компиляции. Иначе он тоже выдаст ошибку.




### Задание 2 **(2)**
*Проверьте работу следующей программы на С++*
```
#include <iostream>
int main() {
   {
      int x, y;
      std::cin >> x >> y;
      std::cout << x+y << std::endl;
   }
   {
      double x, y;
      std::cin >> x >> y;
      std::cout << x+y << std::endl;
   }
   return 0;
}
```
*Нужны ли в этой программе вложенные фигурные скобки? Дайте подробный ответ с объяснением причин.*

### Ответ:

В этой записи внутренние скобки нужны, чтобы разделить переменные с одинаковыми именами.

В первом блоке x и y имеют тип int. После закрывающей скобки они больше недоступны. Во втором блоке создаются уже другие x и y, с типом double.

Если убрать обе пары внутренних скобок, получится повторное объявление одних имен в одном месте, и программа не соберется. Чтобы обойтись без этих блоков, достаточно переименовать переменные.




### Задание 3 **(2)**
*Проверьте работу следующего фрагмента программы на С++.*
```
int s = 0;
for (int i = 0; i < 4; i++) {
   for (int i = 0; i < 3; i++) {
      s += i;
   } 
   s += i; 
}
std::cout << s;
```
*В результате каких вычислений был получен ответ? Дайте подробный ответ.*

### Ответ:

Программа выводит 18. Во внешнем и внутреннем циклах объявлены разные переменные i. Внутренний цикл не меняет внешнюю i.

Внутренний цикл каждый раз прибавляет 0 + 1 + 2 = 3. После него прибавляется внешняя i, которая принимает значения 0, 1, 2, 3:

```text
s = (3 + 0) + (3 + 1) + (3 + 2) + (3 + 3) = 18.
```



### Задание 4 **(2)**

*Проверьте работу следующего фрагмента программы на* **Python**.
```
s = 0
for i in range(4):
   for i in range(3):
      s += i
   s += i
print(s)
```
*В результате каких вычислений был получен ответ? Дайте подробный ответ.*

*На основе этих примеров поясните различия между* **С++** и **Python** *при работе с переменными*.

### Ответ:

Программа выводит 20. В Python оба цикла используют одно имя i. После внутреннего цикла в нем остается 2.

Поэтому за один проход внешнего цикла прибавляется:

```text
0 + 1 + 2 + 2 = 5.
```

Внешний цикл берет очередные значения из range(4) и делает 4 прохода. Получаем s = 4 * 5 = 20.

Разница в том, что в C++ внутренний int i создает отдельную переменную. В Python цикл for отдельную область для переменных не создает.

### Задание 6 **(2)**

*Рассмотрим следующий фрагмент программы. Эта программа 1000000 раз обменивает значения двух длинных 
строк с использованием третьей строки. Проверьте, насколько быстро она работает.*

```
std::string a(100000, 'a');
std::string b(100000, 'b');
for (int i=0;i<1000000;i++) {
   std::string c(a);
   a = b;
   b = c;
}
std::cout << a[0] << b[0];
```
*Попробуйте использовать для обмена значений строк функцию* **swap**. 
*Проверьте, изменилось ли время работы. В чем ошибка исходной программы?
Исправьте исходную программу, чтобы ускорить ее работу. Изменения не должны 
затрагивать общий вид программы (присваивания, использование временной переменной).*

### Ответ:

При проверке получилось:

```text
Копирование: около 8.42 с.
swap: около 0.0034 с.
Перемещение: около 0.0078 с.
```

Время на другом компьютере может отличаться. Все варианты выводят ab, потому что число обменов четное.

Проблема исходной программы в лишнем копировании: на каждом шаге целиком копируются три длинные строки. Вместо этого можно обменять их внутренние данные:

```cpp

```

```cpp

    std::string c(std::move(a));
    a = std::move(b);
    b = std::move(c);
}
```

Для std::move нужен заголовок <utility>. В этом случае передается память с символами строки, а сами символы заново не копируются.




### Задание 7 **(2)**

*Рассмотрим программу на языке* **Python**.
```
a = 'Hello world'
print(a, id(a))
b = a
print(b, id(b))
a += ' and goodbye'
print(a, id(a))
print(b, id(b))
```
*Объясните ее работу. В какой момент создавались строки? 
Что означает значение, возвращенное функцией* **id**?

### Ответ:

Сначала a ссылается на строку 'Hello world'. После b = a оба имени ссылаются на одну строку, поэтому их id совпадают. Новая строка при таком присваивании не создается.

Строки нельзя менять на месте. Поэтому после a += ' and goodbye' имя a ссылается на новую строку 'Hello world and goodbye'. У b остается старая строка 'Hello world'.

id возвращает идентификатор объекта. У одного объекта он не меняется, пока объект существует. В обычной реализации Python это его адрес в памяти, поэтому конкретные числа при разных запусках могут отличаться.



### Задание 8 **(2)**

*Пусть* **a** - *строковая переменная в программе на* **Python**.
*Есть ли разница между работой присваивания*
```b = a```
и
```b = a[:]```
*Напишите программу для демонстрации различий.*

### Ответ:

Для строки оба способа дают одинаковое содержимое. b = a сохраняет ссылку на строку, а a[:] берет ее целиком. Так как строки неизменяемые, Python может вернуть тот же объект без создания копии.

```python
a = input()
b = a
c = a[:]
print(a == b == c)
print(a is b, a is c)
a += '!'
print(a, b, c)
```

Первая проверка выводит True: содержимое одинаковое. В обычной реализации Python вторая проверка выводит True True: объекты тоже совпадают. Однако совпадение объектов при срезе не гарантируется во всех реализациях.

После a += '!' у a появляется новое значение, а у b и c остается прежняя строка.



###  Задание 9 **(3)**
*Напишите программу на языке* **Python**, *которая создаст 2600 переменных с именами
от* **a0** *до* **a99**, *от* **b0** *до* **b99** *и так далее, от* **z0** *до* **z99**. 
*Присвойте всем переменным различные значения от 1 до 2600.*

### Ответ:

```python
for i, letter in enumerate('abcdefghijklmnopqrstuvwxyz'):
    for j in range(100):
        globals()[f'{letter}{j}'] = i * 100 + j + 1

print(a0, a99, b0, z99)
```

globals() позволяет создать переменную с именем, записанным в строке. Внешний цикл перебирает буквы, внутренний числа от 0 до 99.

Формула i * 100 + j + 1 дает значения от 1 до 2600 без повторений. Последняя строка выводит 1 100 101 2600.
