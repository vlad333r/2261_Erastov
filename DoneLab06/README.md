### Задание 1 **(3)**
*Рассмотрим следующую программу на С++.*
```
#include <iostream>
#include <cmath>
int main() {
   double x = 0;
   const auto Pi = std::acos(0) * 2;
   std::cout << Pi << std::endl;
   return 0;
}
```
*Проверьте четыре способа объявления* **Pi**.
* ```const auto Pi = acos(0) * 2;```
* ```constexpr auto Pi = std::acos(0) * 2;```
* ```const auto Pi = acos(x) * 2;```
* ```constexpr auto Pi = std::acos(x) * 2;```

*Что можно сказать об этих вариантах? Проверьте, в каких вариантах объявляется константа этапа трасляции.*

*Тексты программ разместите в папке с номером задания*

### Ответ:

1. const с acos(0): работает, но Pi не является константой этапа трансляции.
2. constexpr с acos(0): работает, Pi является константой этапа трансляции.
3. const с acos(x): работает, но Pi не является константой этапа трансляции.
4. constexpr с acos(x): ошибка, так как x не является constexpr.

const запрещает изменение, а constexpr требует вычислить значение при компиляции. Второй вариант GCC разрешает как расширение: в C++17 это не гарантировано стандартом.





### Задание 2 **(2)**
*Проверьте работу следующей программы на С++*
```
#include <iostream>
int main() {
   {
      int x, y;
      std::cin >> x >> y;
      std::cout << x+y << std::endl;
   }
   {
      double x, y;
      std::cin >> x >> y;
      std::cout << x+y << std::endl;
   }
   return 0;
}
```
*Нужны ли в этой программе вложенные фигурные скобки? Дайте подробный ответ с объяснением причин.*

### Ответ:

Скобки создают разные области видимости. Поэтому int x, y и double x, y не мешают друг другу.

Если убрать обе пары внутренних скобок, будет ошибка повторного объявления имен. Без блоков нужно дать переменным разные имена.

### Задание 6 **(2)**

*Рассмотрим следующий фрагмент программы. Эта программа 1000000 раз обменивает значения двух длинных 
строк с использованием третьей строки. Проверьте, насколько быстро она работает.*

```
std::string a(100000, 'a');
std::string b(100000, 'b');
for (int i=0;i<1000000;i++) {
   std::string c(a);
   a = b;
   b = c;
}
std::cout << a[0] << b[0];
```
*Попробуйте использовать для обмена значений строк функцию* **swap**. 
*Проверьте, изменилось ли время работы. В чем ошибка исходной программы?
Исправьте исходную программу, чтобы ускорить ее работу. Изменения не должны 
затрагивать общий вид программы (присваивания, использование временной переменной).*

### Ответ:


```text
Копирование: 8.415132 с.
swap:        0.003379 с.
Перемещение: 0.007802 с.
```

Исходный код работает правильно, но каждый обмен трижды копирует длинную строку. swap работает намного быстрее:

```cpp
std::swap(a, b);
```

Сохраняем временную переменную и присваивания, но заменяем копирование перемещением:

```cpp
for (int i = 0; i < 1000000; i++) {
    std::string c(std::move(a));
    a = std::move(b);
    b = std::move(c);
}
```

Нужен <utility>. Перемещение передает буфер без копирования символов. Все варианты выводят ab. Время зависит от компьютера.

###  Задание 9 **(3)**
*Напишите программу на языке* **Python**, *которая создаст 2600 переменных с именами
от* **a0** *до* **a99**, *от* **b0** *до* **b99** *и так далее, от* **z0** *до* **z99**. 
*Присвойте всем переменным различные значения от 1 до 2600.*

### Ответ:

```python
for i, letter in enumerate('abcdefghijklmnopqrstuvwxyz'):
    for j in range(100):
        globals()[f'{letter}{j}'] = i * 100 + j + 1

print(a0, a99, b0, z99)
```

globals() создает имена в глобальном пространстве. Значения идут от 1 до 2600 без повторений. Вывод: 1 100 101 2600.
