### Задание 1 **(2)**
*Рассмотрим программу на языке* **Python**.
```
x = [int(t) for t in input().split()]
for i in range(len(x)):
   if x[i] < i or x[i] > 2*i:
      break
print(i)
```
*Перепишите эту программу так, чтобы в ней использовался цикл* **while**, *в ней не использовалась
инструкция* **break**, *а используемый алгоритм не изменился. Полученная программа должна иметь следующий 
вид.*
```
x = [int(t) for t in input().split()]
i = 0
while ...:
   i += 1
print(i)
```
*Допишите правильное логическое выражение вместо многоточия. Выражение не должно содержать оператор* **not**.

### Ответ:

```python
x = [int(t) for t in input().split()]
i = 0
while i + 1 < len(x) and i <= x[i] <= 2 * i:
    i += 1
print(i)
```

Идем дальше, пока число x[i] лежит между i и 2*i. Если оно не подходит, while заканчивается. Проверка i + 1 < len(x) нужна, чтобы в конце получить последний индекс, как в исходном for, и не выйти за список. Вводим хотя бы одно число.



### Задание 2 **(2)**
*Рассмотрим программу на языке* **Python**.
```
x = [int(t) for t in input().split()]
for i in range(len(x)):
   if i <= x[i] < 2*i or 3*i <= x[i] < 4*i:
      break
print(i)
```
*Перепишите эту программу так, чтобы в ней использовался цикл* **while**, *в ней не использовалась
инструкция* **break**, *а используемый алгоритм не изменился. Полученная программа должна иметь следующий 
вид.*
```
x = [int(t) for t in input().split()]
i = 0
while ...:
   i += 1
print(i)
```
*Допишите правильное логическое выражение вместо многоточия. Выражение не должно содержать оператор* **not**.

### Ответ:

```python
x = [int(t) for t in input().split()]
i = 0
while (i + 1 < len(x)
       and (x[i] < i or x[i] >= 2 * i)
       and (x[i] < 3 * i or x[i] >= 4 * i)):
    i += 1
print(i)
```

В исходном коде поиск заканчивается, когда число попадает хотя бы в один из двух промежутков. Значит, while должен работать, пока число находится вне обоих. Поэтому внутри каждого условия стоит or, а между ними and. Проверка длины оставляет i на последнем индексе. Список должен быть непустым.

### Ответ:

```java
public class main {
    public static void main(String[] args) {
        int[][] x = {{6, 4, 2}, {9, 0, 7}, {0, 3, 8}};
        circle:
        for (int i = 0; i < x.length; i++) {
            for (int j = 0; j < x[i].length; j++) {
```
