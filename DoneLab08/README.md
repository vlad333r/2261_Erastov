*Рассмотрим программу на языке* **Python**.
```
x = [int(t) for t in input().split()]
for i in range(len(x)):

```
*Перепишите эту программу так, чтобы в ней использовался цикл* **while**, *в ней не использовалась

```
x = [int(t) for t in input().split()]
```

```
x = [int(t) for t in input().split()]
for i in range(len(x)):
   if i <= x[i] < 2*i or 3*i <= x[i] < 4*i:

```
*Перепишите эту программу так, чтобы в ней использовался цикл* **while**, *в ней не использовалась
инструкция* **break**, *а используемый алгоритм не изменился. Полученная программа должна иметь следующий 
вид.*
```
x = [int(t) for t in input().split()]
i = 0
while ...:
   i += 1
print(i)
```
*Допишите правильное логическое выражение вместо многоточия. Выражение не должно содержать оператор* **not**.

### Ответ:

```python
x = [int(t) for t in input().split()]
i = 0
while (i + 1 < len(x)
       and (x[i] < i or x[i] >= 2 * i)
       and (x[i] < 3 * i or x[i] >= 4 * i)):
    i += 1
print(i)
```

В исходном коде поиск заканчивается, когда число попадает хотя бы в один из двух промежутков. Значит, while должен работать, пока число находится вне обоих. Поэтому внутри каждого условия стоит or, а между ними and. Проверка длины оставляет i на последнем индексе. Список должен быть непустым.

```java
public class main {
    public static void main(String[] args) {
        int[][] x = {{6, 4, 2}, {9, 0, 7}, {0, 3, 8}};
        circle:

            for (int j = 0; j < x[i].length; j++) {
```

### Задание 4 **(2)**

*Рассмотрим программу на языке* **Python**.
```
a = list(range(10))
b = [a.pop() - x for x in a]
print(*b)
```
*Объясните, почему список* **b** *получился именно таким.*


### Ответ:

Вывод:

```text
9 7 5 3 1
```

Здесь список меняется прямо во время перебора. x берет элементы с начала, а pop() забирает и удаляет последний элемент:

```text

```

После пяти шагов в a остались только числа от 0 до 4. Перебор уже дошел до конца этого укороченного списка, поэтому на этом все.




### Задание 5 **(2)**

*Напишите программу на С++, которая прочитает натуральное число* **n**, *создаст вектор
из* **n** *элементов, прочитает значения элементов, добавит последний элемент вектора к каждому элементу 
(в том числе и к последнему), найдет и выведет количество положительных и отрицательных элементов вектора
после изменения. Из циклов в программе можно использовать только циклы по коллекции.*

### Ответ:

```cpp
#include <iostream>
#include <vector>

int main() {
    int n;
    std::cin >> n;
    std::vector<long long> a(n);
    for (auto& value : a) std::cin >> value;
    long long last = a.back();
    int positive = 0, negative = 0;
    for (auto& value : a) {
        value += last;
        if (value > 0) positive++;
        if (value < 0) negative++;
    }
    std::cout << positive << " " << negative;
}
```

Сначала вводим n, затем n целых чисел. Последнее число заранее сохраняем в last, чтобы прибавлять ко всем именно его исходное значение. После прибавления сразу считаем положительные и отрицательные элементы. Нули пропускаем. В выводе сначала идет число положительных, затем отрицательных.

### Задание 7 **(2)**

*Напишите программу на языке* **Python** *для проверки того, что все числа во введенной 
последовательности неотрицательные. Если в цикле будет найдено отрицательное число, цикл должен
прерваться и вывести найденное число. Если отрицательных чисел нет, то вывести некоторое сообщение об этом.*

*Программа должна использовать конструкцию* **for break else**.

*Запишите аналогичную программу на С++. Какие изменения в алгоритме решения в ней появились?. Почему?*

*Написанные программы сохраните в папку с номером задания.*

### Ответ:

Python, числа вводятся одной строкой:

```python
x = list(map(float, input().split()))
for value in x:
    if value < 0:
        print(value)
        break
else:
    print('Отрицательных чисел нет')
```

Если встретилось отрицательное число, выводим его и выходим через break. Если весь список пройден без break, выполняется else и выводится сообщение.

C++, сначала вводится n, затем n чисел:

```cpp
#include <iostream>
#include <vector>

int main() {
    int n;
    std::cin >> n;
    std::vector<double> x(n);
    for (double& value : x) std::cin >> value;
    bool found = false;
    for (double value : x) {
        if (value < 0) {
            std::cout << value;
            found = true;
            break;
        }
    }
    if (!found) std::cout << "Отрицательных чисел нет";
}
```

В C++ у цикла нет else, поэтому нужна переменная found. Если нашли отрицательное число, ставим true. После цикла проверяем found: если там осталось false, отрицательных чисел не было.
