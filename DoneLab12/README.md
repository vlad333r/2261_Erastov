### Задание 1 **(2)**

*Запишите класс* **box** *с тремя скрытыми полями типа с плавающей
точкой:* **length**, **widht**, **height**. *Добавьте в класс инициализирующий
конструктор. Найдите размер одного объекта этого класса с
использованием* **sizeof**.


### Ответ:

```cpp
class box {
private:
    double length;
    double width;
    double height;
public:
    box(double _length, double _width, double _height):
        length(_length), width(_width), height(_height) {
    }
};
```

private скрывает поля. После двоеточия конструктор сразу задает их значения: length(_length), width(_width), height(_height).

```cpp

std::cout << sizeof(a) << std::endl;
```

### Задание 7 **(2)**

*Напишите программу на Python в которой будет определяться
класс* **Point** *с двумя полями* **x** *и* **y**. *Класс должен содержать
конструктор и метод* **__str__** *для создания текстового представления
точки. 

Напишите программу для проверки работы методов.*

### Ответ:

```python
class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __str__(self):
        return '(' + str(self.x) + ', ' + str(self.y) + ')'

a = Point(10, 5)
print(a)
```

Метод __init__ работает как конструктор: задает координаты при создании объекта. __str__ делает строку из объекта для print. Это специальные методы с двойными подчеркиваниями, а не скрытые. self это сам объект, self.x и self.y его поля. Они хранятся в словаре self.__dict__. Вывод: (10, 5).

### Задание 8 **(2)**

*Напишите программу на Python в которой будет определяться класс*
**Rectangle** *с двумя полями типа* **Point**. *Точки задают левый верхний
и правый нижний угол прямоугольника. Класс должен содержать
конструктор и метод* **__str__** *для создания текстового представления
прямоугольника. 

Напишите программу для проверки работы методов.*

### Ответ:

```python
class Rectangle:
    def __init__(self, a, b):
        self.topleft = a
        self.bottonright = b

    def __str__(self):
        return '|' + str(self.topleft) + '-' + str(self.bottonright) + '|'

r = Rectangle(Point(0, 10), Point(10, 0))
print(r)
```

Сохраняем два угла в topleft и bottonright. __str__ делает строку из этих точек. Вывод: |(0, 10)-(10, 0)|.

### Задание 9 **(2)**

*Добавьте в класс функцию для вычисления площади

определения класса, а в процессе работы программы.*

*Проверьте работоспособность функции.*

### Ответ:

                                    (self.topleft.y - self.bottomright.y))

Добавляем square в класс через lambda уже после создания r. Площадь это ширина на высоту, abs убирает минус. Получается 10 * 10 = 100.
